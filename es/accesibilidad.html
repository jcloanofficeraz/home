Declaración de Accesibilidad

Nuestro compromiso con hacer que este sitio web sea accesible para todos.

Estamos comprometidos a hacer que jcloanofficer.com sea accesible para todos, incluyendo personas con discapacidades. Nuestra meta es que este sitio web cumpla con las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1, Nivel AA.

Medidas Que Tomamos

  • HTML semántico y una estructura clara de encabezados para apoyar a lectores de pantalla
  • Texto alternativo descriptivo para imágenes con contenido significativo
  • Contraste de color suficiente entre el texto y el fondo
  • Todos los elementos interactivos (menús, botones, formularios) operables con teclado
  • Indicadores visibles de foco para la navegación con teclado
  • Compatibilidad con zoom del navegador hasta 200% sin pérdida de contenido o funcionalidad
  • Respeto a las preferencias de movimiento reducido

Contenido de Terceros

Algunas partes de este sitio dependen de servicios de terceros, como nuestro formulario de contacto de JotForm y el widget de agenda de Calendly. Aunque elegimos proveedores que priorizan la accesibilidad, no controlamos directamente su código y no podemos garantizar el cumplimiento total de ese contenido embebido.

Esfuerzos Continuos

La accesibilidad es un proceso continuo. Revisamos y actualizamos este sitio periódicamente para identificar y corregir barreras a medida que las encontramos.
